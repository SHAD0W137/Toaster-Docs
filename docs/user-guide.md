# Руководство пользователя

<a id="auth"></a>
### Авторизация и профиль
Платформа поддерживает вход через стандартную связку Login/Pass, а также OAuth 2.0 (Google, GitHub). В профиле пользователя сохраняется история всех пройденных тестов и статистика прогресса.

<a id="kb"></a>
### Работа с Базой знаний
База знаний построена по иерархическому принципу:
`Категория (Предмет) -> Раздел (Тема) -> Статья`.

* **Поиск**: осуществляется по ключевым словам и тегам.
* **Предложение правок**: любой пользователь может предложить изменение. Модератор проверит его в течение 24 часов.

<a id="tests"></a>
### Генерация тестов (AI Mode)
Главная фишка ToasterEX — модуль **Toaster-AI**.
1. Нажмите кнопку "Создать тест".
2. Загрузите файл (лекция, конспект) в формате `.pdf` или `.docx`.
3. ИИ проанализирует текст и сформирует от 10 до 30 вопросов.
4. Выберите режим:
    * **Заучивание**: вы видите правильный ответ сразу после выбора.
    * **Экзамен**: результат доступен только в конце, время ограничено.
