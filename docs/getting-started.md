# Быстрый старт

### Системные требования
* **Браузер**: Chrome 90+, Firefox 88+, Safari 14+.
* **Мобильная ОС**: iOS 13+ / Android 9+.
* **Интернет**: стабильное соединение от 1 Мбит/с.

### Первый вход
1. Перейдите по адресу платформы.
2. Нажмите "Регистрация". 
3. Подтвердите e-mail (в демо-режиме подтверждение происходит автоматически).
4. Выберите вашу роль: **Студент** или **Преподаватель**.

> [!TIP]
> Для получения доступа к ИИ-функциям (генерация по PDF) необходимо активировать Pro-статус в настройках профиля.
