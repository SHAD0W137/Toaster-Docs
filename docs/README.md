# Платформа ToasterEX
> База знаний и ИИ-генератор тестов.

Добро пожаловать в официальную документацию проекта. 

### Основные возможности
* **Smart-генерация**: создание тестов по PDF/Docx.
* **База знаний**: структурированное хранение учебных материалов.
* **AI-Ассистент**: проверка развернутых ответов в режиме реального времени.

*Раздел находится в процессе наполнения согласно спринту №4.*
